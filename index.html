Politique de Confidentialité

Todo Timer App

Dernière mise à jour : 15 janvier 2025

🔒 Engagement de Confidentialité

Todo Timer App s'engage à protéger votre vie privée. Cette politique explique comment nous collectons, utilisons et protégeons vos informations personnelles.

1. Introduction

Todo Timer App ("nous", "notre", "l'application") s'engage à protéger votre vie privée. Cette politique de confidentialité explique comment nous collectons, utilisons et protégeons vos informations personnelles lorsque vous utilisez notre application mobile.

2. Informations que nous collectons

2.1 Informations que vous fournissez directement

  • Tâches et descriptions : Titre, description, catégorie et priorité de vos tâches
  • Données de timer : Durée estimée et réelle des tâches, temps de travail
  • Tags personnalisés : Étiquettes que vous créez pour organiser vos tâches
  • Préférences : Paramètres de l'application et configurations personnalisées

2.2 Informations collectées automatiquement

  • Données d'utilisation : Temps passé sur l'application, fonctionnalités utilisées
  • Données de performance : Statistiques de productivité et métriques de timer
  • Données techniques : Version de l'application, système d'exploitation, identifiant unique de l'appareil

2.3 Informations de l'appareil

  • Permissions : Accès aux notifications, vibrations, et mode veille
  • Données de stockage local : Toutes vos données sont stockées localement sur votre appareil

3. Comment nous utilisons vos informations

Nous utilisons vos informations pour :

  • Fonctionnalités principales : Gérer vos tâches, timers et notifications
  • Améliorer l'application : Analyser l'utilisation pour optimiser les fonctionnalités
  • Support technique : Résoudre les problèmes et fournir une assistance
  • Notifications : Vous alerter des rappels de timer et accomplissements de tâches

4. Stockage et sécurité des données

4.1 Stockage local

  • Base de données Hive : Toutes vos données sont stockées localement sur votre appareil
  • Aucune synchronisation cloud : Vos données ne quittent jamais votre appareil
  • Chiffrement local : Les données sensibles sont protégées par le système de sécurité de votre appareil

4.2 Sécurité

  • Accès restreint : Seul vous avez accès à vos données
  • Pas de collecte externe : Aucune donnée n'est transmise à des serveurs tiers
  • Protection par mot de passe : Utilisez les fonctionnalités de sécurité de votre appareil

⚠️ Important

Nous ne partageons JAMAIS vos données personnelles avec des tiers, car :

  • Toutes les données restent sur votre appareil
  • Aucune synchronisation cloud n'est effectuée
  • Aucun service d'analyse externe n'est utilisé
  • Aucune donnée n'est transmise à des serveurs

5. Permissions de l'application

5.1 Android

  • RECEIVE_BOOT_COMPLETED : Redémarrer les timers après redémarrage
  • VIBRATE : Vibrations pour les notifications
  • WAKE_LOCK : Maintenir l'écran allumé pendant les timers
  • POST_NOTIFICATIONS : Afficher les notifications de timer

5.2 iOS

  • Notifications locales : Pour les rappels de timer
  • Mode arrière-plan : Pour maintenir les timers actifs

6. Vos droits

Vous avez le droit de :

  • Accéder à toutes vos données (stockées localement)
  • Modifier vos données à tout moment dans l'application
  • Supprimer vos données en désinstallant l'application
  • Exporter vos données via les fonctionnalités d'export de l'application
  • Contrôler les notifications dans les paramètres de l'appareil

7. Données des mineurs

Notre application ne collecte pas sciemment d'informations personnelles d'enfants de moins de 13 ans. Si vous êtes parent et que vous découvrez que votre enfant nous a fourni des informations personnelles, contactez-nous.

8. Modifications de cette politique

Nous pouvons mettre à jour cette politique de confidentialité occasionnellement. Nous vous informerons de tout changement significatif via :

  • Une notification dans l'application
  • Une mise à jour de cette page
  • Un message lors de la prochaine ouverture de l'application

9. Conformité légale

Cette politique est conforme au :

  • RGPD (Règlement Général sur la Protection des Données) de l'UE
  • CCPA (California Consumer Privacy Act) des États-Unis
  • Loi sur la protection des renseignements personnels du Canada
